# HHR Nexus CSV quality audit

**5 USDC per file** — an AI-assisted, fixed-scope report you can reproduce.

For one authorized, non-sensitive UTF-8 CSV up to 5 MB and 10,000 data rows, HHR Nexus checks row shape, blank cells, normalized duplicate rows, outer whitespace and formula-like values. Delivery consists of a Markdown/JSON audit, a normalized CSV preserving all source rows, and file hashes. No values are guessed; formulas are never executed.

Delivery target: one day after a confirmed work agreement and receipt of suitable input. We do not ask for store logins, production access, private keys, API keys, confidential customer data or funds before an agreed order and verified payment instructions.
